# Naguru Shivaganesh — Portfolio Website

A responsive, static portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — all page content and 10 portfolio sections
- `styles.css` — responsive premium dark visual design
- `script.js` — mobile navigation, reveal effects, FAQ interaction

## Run locally
Open `index.html` in a browser. For a local development server, use VS Code Live Server or run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Publish free with GitHub Pages
1. Create a public repository named `shivaganesh720.github.io` (or another repository name).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. If using the special repository name `shivaganesh720.github.io`, the site URL will be `https://shivaganesh720.github.io/`. Otherwise the URL will include the repository name.
