# Naguru Shivaganesh — Personal Portfolio Website

A fast, responsive, zero-dependency static portfolio built with semantic HTML, modern CSS, and vanilla JavaScript. Fully compatible with free hosting on GitHub Pages.

## Files Included for Deployment
- `index.html` — All 10 portfolio sections, SEO/OpenGraph metadata, and accessible markup
- `styles.css` — Premium dark AI startup aesthetic, glassmorphism cards, responsive layout, and reduced-motion support
- `script.js` — Mobile navigation drawer, scroll-spy, project category filtering, accessible FAQ accordion, and email copy helper
- `profile.png` — Borderless professional portrait photograph

## Preview Locally
Open `index.html` directly in a browser, or run a local HTTP server:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Deploy Free with GitHub Pages
1. Create a public GitHub repository named `shivaganesh720.github.io` (for a root URL at `https://shivaganesh720.github.io/`) or any repository name (e.g., `portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and `profile.png` to the root of the `main` branch.
3. In your repository on GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait 1–2 minutes for GitHub Actions to finish publishing, then open the live URL shown at the top of the Pages settings screen.
